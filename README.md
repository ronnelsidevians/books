# Books PWA v5

## Серії книг
Структура серії:

```text
books/Назва серії/01 Перша книга.pdf
books/Назва серії/02 Друга книга.pdf
```

Назва серії береться з назви підпапки. Початкове число у файлі використовується як порядок і не переноситься в назву книги.

## Пріоритетність
Пріоритет виставляється у картці книги. Зберігається локально в браузері разом із прогресом.
