# Books PWA patch v3

Виправлення:

1. Папка, у якій є тільки підпапки з книгами, тепер показує ці підпапки, а не повідомлення “немає книг”.
2. Шляхи до PDF та `icon.*` у `data/books.json` залишаються сирими (`books/Папка/Книга.pdf`), а `app.js` кодує URL тільки один раз.
3. `app.js` також захищений від старого вже encoded формату (`%D0...`) і не кодує його вдруге.
4. Додано нормальні клікабельні зірочки 1–5 + кнопка `0`.
5. Додано поле коментаря.
6. Старий `progress.json` підтримується. Нові поля необов’язкові: `hidden`, `rating`, `comment`.
7. `sw.js` має новий CACHE, щоб браузер не тримав стару версію `app.js`.

Після заміни файлів запусти:

```bash
python build_library.py
```

У консолі має бути приблизно:

```text
PDF found: 237
Generated data/books.json
```

Після цього закоміть `data/books.json`, `covers/` і файли патчу.
